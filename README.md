# Recur AI Revenue Recovery

A production-oriented AI-powered revenue recovery system designed to automate the processing of failed payment events.

The system performs:

- Payment failure diagnosis
- Recovery strategy planning
- Governance and decision validation
- Recovery action execution
- Persistent data storage
- Analytics and monitoring

The application is built with Python, FastAPI, SQLAlchemy, SQLite, Docker, and GitHub Actions.
